# Phone A Receiver

This receiver is for the private two-phone cybersecurity lab. It accepts synthetic call-log records generated by the lab client and displays them in a local dashboard.

## Run

```bash
pip install -r requirements.txt
python server.py
```

The receiver listens on `0.0.0.0:8080`. For the current lab network, the expected Phone A address is `10.119.176.166`, so the dashboard is:

`http://10.119.176.166:8080/`

Do not expose this service to the public internet.
